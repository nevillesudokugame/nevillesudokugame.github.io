# GitHub Pages upload

Upload the contents of this `website` directory—not the directory itself—to the root of the public `nevillesudokugame.github.io` repository.

Expected public URLs:

- `https://nevillesudokugame.github.io/`
- `https://nevillesudokugame.github.io/privacy/`
- `https://nevillesudokugame.github.io/support/`
- `https://nevillesudokugame.github.io/app-ads.txt`

In GitHub: open the repository, choose **Add file → Upload files**, select `index.html`, `styles.css`, `.nojekyll`, `app-ads.txt`, plus the complete `privacy` and `support` folders, then commit to `main`. Confirm all four URLs after Pages finishes deploying.

`app-ads.txt` intentionally contains no seller record yet. Replace it only with the exact line supplied by the publisher's AdMob account.
